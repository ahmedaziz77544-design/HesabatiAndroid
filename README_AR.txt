حساباتي - مشروع أندرويد تجريبي أصلي (Kotlin + Jetpack Compose)
============================================================

هذه ملفات مشروع تطبيق أندرويد أصلي وليست موقعاً ولا ملف APK جاهزاً.

الموجود حالياً في الكود:
- واجهة عربية من اليمين إلى اليسار.
- شاشة ملخص للمبيعات والمشتريات والمصروفات.
- تسجيل عمليات بسيطة وحفظها محلياً على الجهاز.
- العملات YER وSAR وUSD مع عرض مستقل لكل عملة دون جمعها أو تحويلها.
- تقارير أولية لصافي الحركة داخل العملة نفسها.

غير المكتمل:
- محاسبة إنتاجية بالقيد المزدوج ودليل حسابات ودفتر أستاذ وإقفال فترات.
- العملاء والموردون والمخزون والفواتير والضرائب.
- تعدد الشركات بحسب الباقة والمستخدمون والصلاحيات.
- النسخ الاحتياطي السحابي والمزامنة والعمل دون اتصال مع مزامنة لاحقة.
- الاشتراكات والدفع الإلكتروني ولوحة إدارة المالك.
- اختبارات فعلية على أجهزة سامسونج والنشر.

إنشاء APK عبر GitHub Actions من الهاتف:
1) أنشئ مستودعاً جديداً في GitHub باسم HesabatiAndroid (يمكن جعله Private).
2) فك ضغط ملف ZIP على الهاتف.
3) ارفع محتويات مجلد HesabatiAndroid إلى جذر المستودع، مع الحفاظ على المجلد المخفي .github/workflows/android-apk.yml.
4) اجعل الفرع الافتراضي main. بعد رفع الملفات، افتح تبويب Actions.
5) افتح مهمة Build Hesabati APK وانتظر حتى تصبح جميع الخطوات خضراء.
6) افتح نتيجة التشغيل، ثم Artifacts، ونزّل hesabati-debug-apk.zip.
7) فك ضغط artifact على الهاتف، ثم افتح app-debug.apk للتثبيت.

إذا لم يظهر تبويب Actions أو فشل البناء، راجع إعدادات Actions في المستودع أو أرسل سجل الخطأ.

ملاحظات البناء:
- ملف workflow يستخدم Java 17 وGradle 8.9 وAndroid SDK 35.
- لم يتم تشغيل workflow أو التحقق من نجاحه بعد.
- لم يتم إنشاء APK ضمن هذه الحزمة.
